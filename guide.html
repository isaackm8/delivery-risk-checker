CSV field guide

How to fill in an order file the Delivery Risk Checker can read.

Download the template Download the sample file Open the checker

Quick start

  1. Download the template. It's a CSV file with the 12 column headers and no orders.
  2. Add one row per order in Excel, Google Sheets or any spreadsheet. Keep the header row.
  3. Save as CSV (in Excel: File → Save As → "CSV UTF-8").
  4. Open the checker and drop the file onto the upload box.

Not sure what a filled-in file looks like? Download the sample file: 50 made-up orders that use every column. When you load it in the checker (or click Try it with sample orders), its dates are moved to be current and made-up demo storms are switched on, so it always shows a mix of on-time, at-risk and weather-delayed orders. Your own files are never changed this way.

General rules

  • The first row must be the column headers. Each following row is one order.
  • 9 columns are required, 3 are optional. If a required column is missing, nothing loads and the page lists what's missing.
  • Header names are forgiving: capitals, spaces and hyphens don't matter, so Order ID, order-id and order_id all work. Other names (e.g. Ship To Zip) aren't recognized: rename them to the names below.
  • Column order doesn't matter, and extra columns are ignored, so you can keep your own notes in the file.
  • A value containing a comma (like $1,200.50 or Mug, 12 oz) must be in double quotes. Spreadsheet programs do this for you when saving as CSV.
  • A row with a problem is skipped, not the whole file. Skipped rows are listed at the top of the page with the line number and the reason, so you can fix them and load the file again.
  • Your file stays in your browser. It's never uploaded. To check the weather, only ZIP code center points are sent to the National Weather Service.

The columns

ColumnNeeded?What it meansFormat and rulesExample
order_idRequired Your order number. Any text. Must not be empty. Use a different one for each order: it's how orders are told apart. ORD-20481
customer_nameOptional The customer's name, used to greet them in delay notices. Any text. The first word is used ("Hi Ava"). Blank: "Hi there". Ava Thompson
customer_emailOptional Where to send a delay notice. Must look like name@domain.com. Anything else is treated as missing, and that customer is skipped when notifying. ava@example.com
order_dateRequired The day the customer placed the order. The promised delivery date is this plus 7 business days. YYYY-MM-DD or M/D/YYYY. Must be a real date. Weekend and holiday orders count from the next business day. 2026-10-15
order_valueRequired What the order is worth. A number. $ and thousands commas are fine (quote the value if it has a comma). 64.00
product_nameRequired column What was bought. Any text; may be blank. Shown in the table and the delay notice. Pour-Over Coffee Kit
product_descriptionRequired column A short description of the product. Any text; may be blank. Ceramic dripper and filters
origin_zipRequired The ZIP code the package ships from (your warehouse). A US ZIP code. See ZIP codes for what's accepted. 43228
destination_zipRequired The ZIP code the package is going to. A US ZIP code. See ZIP codes. 02139
ups_service_levelRequired The UPS service the order ships with. One of the names in Service levels. UPS Ground
ship_dateRequired column The day the label was created and UPS picked the package up. YYYY-MM-DD or M/D/YYYY, not before the order date. Leave blank if not shipped yet: the checker then assumes 1 business day of processing. 2026-10-19
tracking_numberOptional The UPS tracking number. It links the order's shipment progress to UPS, and lets a delay notice send the customer to UPS to reroute or hold the package. Every order with a ship_date should have one; if it's missing the order still loads but shows "Tracking # missing". Spaces are removed. Ignored for orders that haven't shipped. 1Z999AA10123456784

ZIP codes

The checker knows the location of 33,791 US ZIP codes, from the US Census Bureau. It uses each ZIP's center point to measure distance and check the weather.

ZIPWhat happens
A regular 5-digit US ZIP, including Alaska, Hawaii, Puerto Rico, Guam and the US Virgin IslandsWorks Exact location.
ZIP+4 (43228-1234)Works Only the first 5 digits are used.
A ZIP that lost its leading zero in Excel (2139 for 02139)Works The zeros are added back.
A ZIP for a single building or PO boxes only (e.g. 10118, 99950)Approximate These aren't in the Census list, so the checker uses the average location of ZIPs with the same first 3 digits, shown as "(approx.)". Usually close enough for distance and weather.
Military APO, FPO and DPO addresses (ZIPs starting 090–099, 340, 962–966)Not supported They have no fixed location, so the row is skipped ("wasn't found").
Canadian or other non-US postal codesNot supported The row is skipped ("isn't a 5-digit ZIP").
A ZIP that doesn't exist, or lettersSkipped With the reason.

Service levels

Write the service as UPS names it. Capitals don't matter, and the word "UPS" is optional.

Accepted nameTransit time used
UPS Next Day Air1 business day
UPS Next Day Air Saver1 business day
UPS 2nd Day Air (or Second Day Air)2 business days
UPS 3 Day Select3 business days
UPS Ground1 to 7 business days, by distance (see the project README)

Other services (e.g. UPS SurePost, Worldwide Express, or other carriers) aren't recognized; those rows are skipped.

Where UPS Ground can go

  • Not to or from Hawaii. Use an air service; Ground rows are skipped with this reason.
  • Not between Alaska and the rest of the US. Ground within Alaska is fine.
  • Puerto Rico, Guam and other territories: UPS Ground doesn't serve them from the mainland either, but the checker doesn't check this yet. A Ground order to a territory gets an ordinary Ground estimate, which will be too optimistic. Use an air service for these.

Dates and "today"

  • Business days are Monday to Friday, skipping New Year's Day, Memorial Day, Independence Day, Labor Day, Thanksgiving and Christmas.
  • The checker judges every order as of today: an order whose expected delivery has passed is treated as likely delivered (it isn't checked for weather and can't be selected for a delay notice). This is a guess from the dates, not tracking.
  • To see a file as of another day, add ?today=YYYY-MM-DD to the checker's address, e.g. index.html?today=2026-10-28.

Before you upload: a quick checklist

  • The header row is there, with the 9 required columns.
  • Every order has an order_id, an order_date and a number in order_value.
  • Both ZIP codes are US ZIPs (no military or foreign addresses).
  • The service level is one of the five UPS names, and Ground isn't used for Hawaii, Alaska-to-mainland or territory orders.
  • ship_date is blank for orders that haven't shipped, and never before the order date.
  • Every shipped order has a tracking_number.
  • To send delay notices: customer_email is filled in.
  • The file is saved as CSV, not as an Excel workbook (.xlsx).
