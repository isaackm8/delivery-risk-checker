# delivery-risk-checker

A prototype tool for spotting deliveries that are at risk of being late or failing, so they can be dealt with early.

## Status

Early prototype. No code yet.

## Goals

- Take delivery data as input (for example, a CSV export)
- Score each delivery's risk (e.g. red / amber / green)
- Explain why each delivery got its score
